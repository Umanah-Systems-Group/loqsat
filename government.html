Built the way a program office needs it.

The rules are in the system, not in a policy binder.

Fails closed

Every action is checked for permission first. If the check does not answer, nothing is sent, and the refusal is recorded.

Each party sees its own

An operator sees only the events it is part of. Both sides of an event see the same entries, and nobody else does.

A record you can check

Every step is sealed in order. Change one line and the check fails at that exact line, so your auditors can verify it themselves.

Standard messages

Warnings are read in the format the space community already uses for close approaches, so no team has to retrain.

Compact to deploy

The whole system is packaged to run on a single server, ours or one in your environment.

Advisory only

LoqSat never commands a spacecraft and never computes collision risk. The operator who flies it decides.
